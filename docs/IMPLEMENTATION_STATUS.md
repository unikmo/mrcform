# MrForm implementation status

- Public pages, navigation and pricing under MrForm name.
- Adviser dashboard and case list using synthetic example only.
- Seven-part case-review demonstration.
- Applicant invitation-flow mockup.
- Legal placeholders and explicit security/production disclaimers.
- CI build, syntax check and static route checks.

## Not implemented / not safe to enable

- Document storage, virus scanning, consent and deletion.
- OCR/extraction, evidence rule engine and official form mappings.
- Export of validated official forms and API/browser integration.
- Stripe billing, metering and invoices.
- Audit logging, GDPR documentation, penetration testing.
- Real applicant invitations.
- End-to-end QA in a deployed browser.
