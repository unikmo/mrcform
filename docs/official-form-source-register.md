## Pilot checklist to build from the local official pack

- [ ] Open the municipal page and download the current Mietzuschuss main application and guidance.
- [ ] Download Lastenzuschuss separately; do not mix the owner route with tenant route.
- [ ] Download each annex and record title, form version/date, exact URL, and retrieval date.
- [ ] Map conditional annex triggers to the official guidance; do not attach every annex to every case.
- [ ] Confirm which evidence checklist applies to the selected case type.
- [ ] Use the synthetic fixture only; resolve its deliberate rent/service-charge contradiction and missing maintenance evidence.
- [ ] Fill a copy of the official PDF only if editable fields and applicable usage permissions allow; otherwise produce a separate synthetic field-mapping report, clearly labelled as not an official submitted form.
- [ ] Independently compare the generated output with the blank original, page by page.
- [ ] Never submit the synthetic case or use it to estimate actual benefit eligibility.
